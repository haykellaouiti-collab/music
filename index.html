Comment obtenir le Client ID Google ?
  1. Console Google Cloud → créer un projet → « API et services » → activer YouTube Data API v3.
  2. Écran de consentement OAuth → ajouter le champ d'application .../auth/youtube (sensible).
  3. Identifiants → créer un « ID client OAuth » de type Application Web, avec pour origine JavaScript autorisée l'adresse exacte de votre site (https://… ou http://localhost). Le fichier ouvert directement (file://) ne fonctionne pas.
  4. Collez l'ID ci-dessus, ajoutez votre e-mail administrateur, enregistrez, puis exportez la configuration.
  5. Verrouillé dehors ? Ajoutez #reset à l'adresse pour effacer les réglages de ce navigateur, ou #admin tant qu'aucune configuration complète n'existe.

À propos de Music

Music est un moteur de recherche de musiques libres de droits. Il interroge en direct Openverse, Jamendo et Internet Archive, trois catalogues ouverts, et propose aussi la recherche sur YouTube pour l'écoute. Vous filtrez par genre (jazz, lo-fi, électro, classique, ambient, ASMR, cinématique…), par ambiance, par licence et par durée, puis vous écoutez, gardez vos favoris et copiez les crédits prêts à coller dans la description d'une vidéo.

Comprendre les licences Creative Commons

  • CC0 / domaine public : aucune obligation, usage commercial permis.
  • CC BY : usage commercial permis à condition de citer l'auteur, le titre, la licence et la source.
  • CC BY-SA : comme CC BY, mais votre création doit être partagée sous la même licence.
  • NC (non commercial) : interdit dans une vidéo monétisée.
  • ND (pas de modification) : le morceau ne peut être ni remixé ni coupé.

Conseils pour les créateurs YouTube

Activez « Usage commercial uniquement » si votre chaîne est monétisée, copiez les crédits dès que vous utilisez un morceau et gardez la page source. Une licence peut changer : vérifiez-la chez l'auteur avant de publier. Les titres YouTube marqués « Écoute seule » ne sont pas réutilisables dans vos vidéos.
